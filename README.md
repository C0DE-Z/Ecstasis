# Ecstasis

*outside of oneself*

A faithful recreation of the **Electro-Harmonix Big Muff Pi V7**, built from the ground up with a few extra features for experimenting with different pedal combinations.

### Features

* Faithful **BIG MUFF V7** recreation
* Optional **pedal stacking**
* Custom enclosure
* Fully documented electronics
* Open-source hardware design

### Enclosure

The enclosure was designed specifically for Ecstasis and can be recreated from the included CAD files.

**[Check out the CAD files for the case →](https://cad.onshape.com/documents/4a616b34c8cebf5af5db81c0/w/c1b61d61beab4ab555bac2e2/e/5e637b2c9b2abae1699ef9a3?renderMode=0&uiState=6a9b2af46ffce9c59fbfa45d)**

### Why Ecstasis?

The goal of this project was to recreate the sound and feel of the classic Big Muff while making the design easier to modify and experiment with. this is also a much cheaper alt then out right buying one.

The pedal can also be used as part of a larger stacked setup, allowing different effects to be combined without needing a separate pedal for every configuration.
