# Ecstasis Mk2
 *to stand outside oneself*

A Fuzz pedal based after the Electro-Harmonix Big Muff Pi V7 (Green Russian)

Powered by 9v battery or DC input 
using cheap and easy to source parts, trying to replacate the sound of the orginal somewhat closely. 



## Improvments from the Mk1
- Optmized track width for 9v powerline
- Fixxed Footprint for the 1/4 inch audio jacking being inverted
- Optimized Part location 
- Lowered VIA count
- Added silkscreen prints to show what each pot does, and for what is in and out.
